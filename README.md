«Остатки Ника 41» — прайс-лист из Excel с поиском и фильтрами
==============================================================

Полноценная страница прайса поверх складского файла `.xls` / `.xlsx`
(Номенклатура · Характеристика (цвет) · Остаток): поиск по любой части слова,
живые фасетные фильтры, группировка по позициям, экспорт. Работает локально —
файл никуда не загружается.

Установка в Chrome
------------------
1. Скачать репозиторий (или `dist/ostatki-nika-41-<version>.zip`, если собирали)
   → `git clone https://github.com/nikalay911-byte/ostatki-nika-41`
2. Открыть `chrome://extensions/`, включить **Режим разработчика** (справа сверху).
3. **Загрузить распакованное расширение** → выбрать папку репозитория (ту, где лежит `manifest.json`).
4. Пиктограмма в тулбаре → «Остатки Ника 41» (или `Alt+Shift+O`). При первой установке
   страница прайса открывается сама.

Собрать zip для раздачи коллегам: `npm install && npm run package`
(файл `dist/ostatki-nika-41-<version>.zip`, распаковать и «Загрузить распакованное» → `dist/stage`).

Быстрый старт
-------------
1. Кнопка **Импорт XLS** (или перетащить файл на страницу, или «Загрузить демо-прайс»).
2. Приложение само находит строку заголовка и колонки. Если уверенности нет —
   открывается окно **«Настроить колонки»**: там же видно лист, предпросмотр и подсветку выбранных колонок.
3. Печатайте в поиск — фильтрация идёт по мере ввода, все фильтры пересчитываются друг относительно друга.
4. Нужный срез можно выгрузить (Экспорт → XLSX/CSV/TSV/JSON) или скопировать ссылку: `#q=…&color=…`
   открывает страницу сразу с этим поиском и фильтрами.

Поиск
-----
| Что написать | Что найдёт |
|---|---|
| `480` | подстроку в **любом** месте любого слова, во всех колонках |
| `ника полка` | оба слова одновременно (порядок не важен) |
| `ника -хром` | «ника», но без «хром» |
| `"480x320"` | точную фразу (кавычки — без разложения по словам) |
| `ybrf` | «ника» — поиск понимает забытую раскладку клавиатуры |

Регистр, `ё/е`, неразрывные пробелы, дефисы-тире и кавычки-ёлочки нормализуются.
`/` — фокус в поиск, `Esc` — очистить, `↑`/`↓` — переход по строкам.

Фильтры
-------
* **Наличие**: в наличии / мало (порог настраивается) / нет / минус.
* **Цвет, характеристика** — со свотчами и собственным поиском по списку.
* **Склад**, **диапазон остатка** (плюс быстрые срезы «≥ 1», «≥ 10», «= 0»), **диапазон цены**.
* Счётчики в фильтрах считаются «с учётом остальных фильтров, кроме своего», поэтому список
  значений не схлопывается и любой фильтр можно поправить в один клик (нули приглушены).
* **Спецификации** — режим группировки: одна строка = одна номенклатура, сумма остатков по всем
  цветам/складам, раскрытие по клику.
* Клик по строке — панель подробностей: все колонки файла + другие варианты этой же позиции.

Файл прайса
-----------
Понимаются `.xls` (Excel 97–2003, в т. ч. с кириллицей в codepage 1251), `.xlsx`, `.xlsm`,
`.xlsb`, `.csv`, `.txt`, `.ods`. Особенности реальных прайсов обработаны заранее:

* заголовок может быть не в первой строке (титул, дата, пустые строки) — строка шапки ищется по ключевым словам;
* двухуровневые шапки («Остатки» → «Склад 1 / Склад 2») склеиваются, объединённые ячейки достраиваются;
* строки `ИТОГО`/`ВСЕГО` и повтор шапки на «второй странице» исключаются;
* остаток вида `1 234,5`, `12 шт.`, `нет`, `-`, `−3` понимается как число (текст сохраняется и виден в деталях);
* листов может быть несколько — выбирается самый похожий на прайс, переключается в окне настройки колонок;
* лишние колонки (артикул, цена, склад, единицы, произвольные) не мешают и показываются в таблице и экспорте.

Обновление прайса
-----------------
Если файл выбран кнопкой **Импорт XLS** (не перетаскиванием), Chrome запоминает к нему доступ:
появляется **↻ Обновить** (перечитать тот же файл, фильтры и поиск сохраняются) и **⏱ Авто** —
перечитывание каждые 5–60 минут, пока вкладка открыта. Разбивка по колонкам при этом не «плывёт».

Настройки
---------
Шестерёнка на странице прайса или `chrome://extensions` → «Остатки Ника 41» → «Настройки».

Плотность строк, порог «мало», вид по умолчанию, тема, интервал автообновления,
сколько значений цвета показывать, помнить ли разбивку колонок. Хранятся локально.

Без расширения
--------------
Тот же интерфейс работает как обычная страница: откройте `app/index.html`
(двойным кликом или на GitHub Pages). Разница одна: на `file://` браузер запрещает
IndexedDB, поэтому прайс живёт до закрытия вкладки — сохраните срез через «Экспорт».

Структура
---------
```
manifest.json          MV3: popup, background, options, строгий CSP (без unsafe-eval)
background.js           вкладка прайса + бейдж с числом найденных позиций
app/index.html          страница прайса (она же — «сайт»)
app/js/util.js          нормализация текста, разбор чисел, подсветка совпадений, DOM-хелперы
app/js/parse.js         чтение workbook → поиск шапки → определение колонок → датасет
app/js/filters.js       поисковый индекс, запрос, фасетные счётчики, сортировка, группировки
app/js/store.js         IndexedDB: датасеты чанками, настройки, состояние (fallback для file://)
app/js/fs.js            File System Access: запомнить файл, перечитать, автообновление
app/js/app.js           состояние страницы, виртуальная таблица, фасеты, экспорт, модалки
app/css/app.css         светлая/тёмная темы, печать
popup/                  быстрый поиск по сохранённому прайсу
options/                страница настроек
vendor/xlsx.full.min.js SheetJS 0.18.5 (CSP-safe копия, без eval)
demo/                   демо-прайс: .xls, .xlsx, .csv + demo-data.js для кнопки «демо»
icons/                  процедурная иконка (16/32/48/128)
tools/                  тесты, бенчмарк, генераторы демо/иконок, сборка zip
```

Разработка
----------
Нужен Node ≥ 20.19 (для инструментов и тестов; CI гоняет 22 — на Node 20 jsdom 30 уже не заводится).
Само расширение не требует ни сборки, ни Node: достаточно папки с `manifest.json`.

```bash
npm install
npm test          # 50 проверок: парсер, поиск, фасеты + прогон реальной страницы в jsdom
npm run bench     # импорт и поиск на 100 000 строк
npm run demo      # перегенерировать demo/*.{xls,xlsx,csv} и demo/demo-data.js
npm run icons     # перегенерировать иконки
npm run vendor    # обновить SheetJS из node_modules (с проверкой на eval/CSP)
npm run package   # dist/ostatki-nika-41-<version>.zip
npm run serve     # превью страницы: http://localhost:8080/app/index.html
```
Расширение намеренно **без сборки**: правите JS — просто перезагрузите расширение на `chrome://extensions`.

Приватность
-----------
Разрешение одно — `storage`. Сетевых запросов нет: файл читается во вкладке, хранится в IndexedDB
этого же расширения. Отчётность/аналитика отсутствуют.

Ограничения
-----------
* Прайс на 100 000+ строк индексируется ~0,5 с и дальше считается по 20–90 мс на запрос — это нормально.
* Формулы Excel читаются как посчитанные значения (SheetJS), макросы не исполняются.
* Защищённый паролем файл и «выгрузка из 1С» в формате `.xls` с бинарным мусором в начале — не всегда разбираются;
  сохраните такое из Excel как `.xlsx`.
* Автообновление работает, пока вкладка открыта (иначе Chrome забирает доступ к файлу).
* Для публикации в Chrome Web Store уберите `index.html` из архива и добавьте иконку 128 без прозрачности —
  сам код к публикации готов.

Публикация в новый репозиторий
------------------------------
Если код нужно переложить из рабочей ветки в отдельный репозиторий (код + тег + релиз с zip +
описание + GitHub Pages одним заходом):

```bash
bash tools/publish-to-new-repo.sh            # DRY=1 — только показать команды
OWNER_REPO=login/repo DST_BRANCH=main bash tools/publish-to-new-repo.sh
```

Скрипт безопасен: работает во временной папке, сначала гоняет тесты, `PAGES=0` — не трогать Pages.
