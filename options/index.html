Что понимает импорт
  • .xls (Excel 97–2003), .xlsx, .xlsm, .xlsb, .csv, .txt, .ods — читаются локально, без загрузки на сервер
  • шапка может быть не в первой строке: «Прайс-лист ООО…», дата, потом заголовки — приложение найдёт нужную строку
  • колонки определяются по названиям и по содержимому; при сомнениях открывается окно «Настроить колонки»
  • строки «ИТОГО / ВСЕГО» и повтор шапки на каждой странице исключаются из данных автоматически
  • остаток «1 234,5», «12 шт.», «нет», «-» понимается как число
