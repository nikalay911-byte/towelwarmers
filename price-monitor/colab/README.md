Монитор цен конкурентов — Google Colab
=====================================

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/nikalay911-byte/towelwarmers/blob/main/price-monitor/colab/price_monitor.ipynb)

Python-версия расширения [`price-monitor`](../README.md). Работает в облаке Google, на компьютере ничего ставить не нужно.
Отчёт такой же, как у расширения:

| Цена товара | Разница в цене в % | Магазин демпинг | Ссылка на магазин конкурента |
|---|---|---|---|
| 23 715 ₽ | −15,00% | santehtop.ru — Да | https://www.santehtop.ru/comfysan-alto-k-018160/ |

Файлы:

| файл | что это |
|---|---|
| `price_monitor.ipynb` | готовый ноутбук, модуль уже встроен. Можно просто загрузить в Colab |
| `pricemon.py` | сам монитор: загрузка, разбор цены, очередь с паузами, отчёт CSV/XLSX |
| `test_pricemon.py` | тесты (`python -m unittest price-monitor/colab/test_pricemon.py`) |
| `make_notebook.py` | пересобирает ноутбук после правок `pricemon.py` |

Как открыть
-----------
**Вариант А — по ссылке.** Нажмите на значок «Open in Colab» выше. Ссылка ведёт на ветку `main`, поэтому работает
после слияния изменений в `main`. Для другой ветки замените в адресе `blob/main` на `blob/<ветка>`.

**Вариант Б — файлом.** Скачайте `price_monitor.ipynb`. Затем на <https://colab.research.google.com>
откройте `Файл → Загрузить блокнот` и выберите этот файл.

**Вариант В — из приватного репозитория.** `Файл → Открыть блокнот → GitHub`, отметить «Include private repos»
и авторизоваться.

Запуск
------
1. `Среда выполнения → Выполнить все` (Ctrl+F9). Первый запуск на 4 встроенных позициях Comfysan
   (14 ссылок, паузы 5–10 с) занимает около 2 минут.
2. **Шаг 2 «Настройки»:** паузы, порог демпинга, исключённые домены. По умолчанию исключены
   `comfysan.ru, comfysan-shop.ru, polotenhik.ru, sancomfgroup.ru, sancomf.ru`.
3. **Шаг 3 «Позиции»:** источник списка.
   * *пример* — 4 позиции Comfysan;
   * *загрузить файл* — CSV, выгруженный из расширения кнопкой «Выгрузить позиции», или Excel с колонками
     `Наименование · Артикул · Наша цена · Ссылка · [Якорь] · [CSS-селектор]` (одна строка — одна ссылка);
   * *Google Таблица* — та же структура на первом листе. Colab попросит разрешить доступ к Google-аккаунту.
4. **Шаг 5 «Отчёт»:** таблица (демпинг подсвечен красным), файлы `конкуренты_<дата>.csv` / `.xlsx`
   и кнопка скачивания. В Excel два листа: «Конкуренты» и «Сводка» (минимальная цена по каждой позиции).
5. **Шаг 6 (по желанию):**
   * копия отчёта на Google Диске и файл `история.csv`, к которому дописывается каждый прогон;
   * выгрузка в Google Таблицу: лист «Конкуренты» перезаписывается, лист «История» пополняется.

Сайты, которые строят страницу через JavaScript
-----------------------------------------------
Например, vseinstrumenti.ru: обычный запрос получает пустую страницу. Впишите такой домен в `USE_BROWSER_FOR`.
Ноутбук установит headless Chromium (Playwright, 1–2 минуты) и будет открывать эти страницы через него.

Как ведёт себя монитор
----------------------
* **Строго по одной странице.** Перед каждым запросом случайная пауза `MIN_PAUSE…MAX_PAUSE` секунд.
  Сайты в очереди чередуются, а `DOMAIN_GAP` задаёт минимальный интервал между запросами к одному сайту.
* **Один честный User-Agent** с пометкой `PriceMonitor/1.0.0`. Прокси и подмены нет.
* **Капчи, Cloudflare, 403 и 429 не обходит.** Такой сайт помечается «Сайт ограничил доступ», и его остальные
  ссылки в этом прогоне пропускаются.
* После ошибок 5xx и сетевых ошибок страница один раз перепроверяется в конце очереди.
* Если артикула нет на странице, в логе появляется «⚠ артикул не найден на странице». Так ловится случай,
  когда ссылка ведёт на другой цвет или модель.
* Разбор цены идёт в том же порядке, что в расширении:
  CSS-селектор → якорь → JSON-LD → микроразметка → meta → цена рядом с артикулом → эвристика.
  Старые, зачёркнутые и «в кредит» цены, а также блоки «похожие товары» отбрасываются.

Ограничения Colab
-----------------
* Бесплатная среда отключается примерно через 90 минут без активности и не позже чем через 12 часов.
  Шаг 7 «Повторять каждые N часов» работает, только пока вкладка открыта. Для ежедневной проверки без
  присмотра нужен планировщик: расширение в Chrome, cron на своём сервере или GitHub Actions по расписанию
  (`python -c "import pricemon as pm; …"`).
* Запросы идут с IP-адресов Google (США/Европа). Некоторые магазины показывают другим регионам другие цены
  или ограничивают доступ. Расширение работает из вашего браузера, поэтому цены в нём «московские».
