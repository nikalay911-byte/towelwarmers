«Монитор цен конкурентов» — расширение Chrome
=============================================

Проверяет цены наших позиций в магазинах-конкурентах **по одной странице за раз с большими паузами**
(по умолчанию случайная пауза 5–10 минут, один и тот же сайт — не чаще раза в 30 минут),
считает отклонение от нашей цены и отмечает демпинг. Результат — таблица в формате:

| Цена товара | Разница в цене в % | Магазин демпинг | Ссылка на магазин конкурента |
|---|---|---|---|
| 23 715 ₽ | −15,00% | santehtop.ru — Да | https://www.santehtop.ru/comfysan-alto-k-018160/ |

Разница = `((цена конкурента − наша цена) / наша цена) × 100`. Цена ниже нашей → «Да»
(порог можно задать в настройках). Таблица выгружается в CSV, который открывается в Excel.

Установка
---------
1. `chrome://extensions/` → включить **Режим разработчика**.
2. **Загрузить распакованное расширение** → выбрать папку `price-monitor`
   (или распаковать `dist/price-monitor-<версия>.zip`, собранный командой `npm run monitor:package`).
3. Откроется панель. При первой установке в неё уже загружены 4 позиции Comfysan
   со ссылками из отчёта: EC-3 120/12 и EC-4 120/18 в оружейной стали, EC-4 120/18 в золоте, Stella EC-6 70/40.
4. Нажать **▶ Старт**. Chrome спросит разрешение открывать сайты из списка — его нужно дать
   (доступ запрашивается только к доменам из ваших ссылок, а не ко всем сайтам).

Как это работает
----------------
* Круг проверки: все ссылки перемешиваются и чередуются по сайтам, чтобы подряд не заходить на один магазин.
* На каждую ссылку открывается **свёрнутое окно** (в настройках можно выбрать фоновую вкладку).
  Дальше: ждём загрузку и ещё 3–7 секунд на отрисовку цены, читаем цену со страницы и закрываем окно.
  Страница открывается обычным браузером с вашими cookies, как если бы вы зашли на неё сами.
* Потом пауза 5–10 минут (случайная) и следующая ссылка. После круга — новый через 24 часа (настраивается).
  Сколько займёт круг, видно в панели: при 100 ссылках и паузе 5–10 минут это около 12,5 часа.
* Если сайт показал капчу, Cloudflare или «превышение числа запросов», **обходить защиту расширение не будет**.
  Сайт ставится на паузу на 6 часов (при повторе пауза удваивается), а его оставшиеся ссылки переходят в следующий круг.
* Цена ищется по порядку:
  1. CSS-селектор, если он задан для ссылки;
  2. разметка schema.org (JSON-LD, microdata);
  3. meta-теги;
  4. цена рядом с артикулом;
  5. крупная цена в блоке товара. Старая (зачёркнутая) цена, рассрочка «от … ₽/мес» и блоки «похожие товары» при этом пропускаются.
* Если на странице **нет нашего артикула**, в отчёте появится ⚠ «проверьте, тот ли это товар».
  Так ловится, например, ссылка на 018436 (никель) вместо 018160 (оружейная сталь).
* При новом демпинге приходит уведомление. На значке расширения — число ссылок с демпингом.

Позиции и ссылки
----------------
Вкладка **«Позиции и ссылки»**: наименование, артикул, наша цена и список ссылок, по одной на строку:

```
https://www.santehtop.ru/comfysan-alto-k-018160/
https://santeh-crystal.ru/…-alto-k-ec-2-12010-belyj-pravyj-ten | EC-3 120/12, оружейная сталь, гальвани
https://shop.ru/item/123 | | .product-card .price-current
# https://временно-отключённая-ссылка.ru/
```

* **якорь** (после первой `|`) — артикул или кусок названия. Нужен, если по ссылке открывается
  список товаров (поиск, категория, блок «похожие»), а не карточка: цена берётся из карточки с этим текстом;
* **CSS-селектор** (после второй `|`) — если цена на сайте не находится сама;
* `#` в начале строки — ссылка отключена.

**Импорт из Excel:** скопируйте колонки `Наименование · Артикул · Наша цена · Ссылка` [· `Якорь` · `CSS-селектор`]
и вставьте их в окно «Импорт» (CSV-файл тоже подходит). Строки с одинаковым артикулом объединяются в одну позицию.
**«Выгрузить позиции»** сохраняет список в том же формате.

Настройки
---------
| Параметр | По умолчанию |
|---|---|
| Пауза между проверками | 5–10 мин (случайно) |
| Один сайт — не чаще | 30 мин |
| Повтор круга | каждые 24 ч (0 — только вручную) |
| Где открывать страницу | свёрнутое окно |
| Пауза сайта после капчи/блока | 6 ч, при повторе ×2 (до 7 дней) |
| Порог демпинга | 0 % (любая цена ниже нашей) |
| Исключённые домены | comfysan.ru, comfysan-shop.ru, polotenhik.ru, sancomfgroup.ru, sancomf.ru |

Ограничения
-----------
* Проверка идёт, только пока открыт Chrome. Если компьютер спал, круг продолжится после пробуждения.
* Ссылки на карточки товаров у конкурентов нужно найти один раз вручную (или импортировать).
  Сам поиск магазинов по Яндексу или Google расширение не делает: поисковики быстро отвечают капчей.
* Ротации прокси, подмены User-Agent, «stealth»-режима и решения капч нет и не будет.
  Расширение ходит на сайты медленно и открыто, как обычный посетитель.

Разработка
----------
```
npm ci
npm run monitor:test      # ядро, извлечение цен в jsdom, круг service worker'а на имитации chrome.*
npm run monitor:package   # dist/price-monitor-<версия>.zip
npm run monitor:icons     # перерисовать иконки
```
Файлы: `background.js` — планировщик и проверка, `lib/core.js` — расписание, расчёты, CSV,
`lib/extract.js` — чтение цены со страницы, `dashboard/` — панель, `popup/` — попап.
